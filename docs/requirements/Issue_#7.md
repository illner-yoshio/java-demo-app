# 要件定義書　タスク一覧の画面表示

## 1. 概要

ToDo管理アプリのメイン画面に、未完了のタスク一覧を表示できるよう実装する。
完了しているタスクについては、将来的に、別メニューページでの表示できるように実装することを想定しており、本Issueのスコープ外とする。

## 2. 対象機能

- タスク表示機能（新規機能）
- Amazon RDS (MySQL)

## 3. ユースケース

- メイン画面で、DBに登録されている未完了タスクを表示する
  -現在対応すべきタスクと、過去に完了したタスクを分離し、現在の作業対象を確認しやすくするため。
-各タスクで表示したい内容は下記
  - No.（ユーザーがタスクを番号で認識するための情報。整数、画面に表示されている順番で表示）
  - 未完了タスク内容
  - 優先度（高、中、低を選択）※将来的に、優先度の分類が増える可能性あり
  - 期日（日付:yyyy-mm-dd形式）

## 4. 機能要件

### 4.1 RDS (MySQL)

ユーザーのタスク内容をテーブルで管理できるようにする。テーブルで保持したい内容は下記。

- タスクID（タスクを一意に識別する番号。整数、自動採番）
- タスク内容（文字）
- 優先度
- 期日（日付、年月日）
- 完了フラグ（完了タスクと未完了タスクを識別できるようにする）
- ユーザーid（どのユーザーのタスクなのかを識別できるようにする）

### 4.2 タスク一覧の表示機能

ユーザーがログイン認証に成功した場合、ログインユーザーに紐付く未完了タスクを取得し、メイン画面に表示する。

### 4.3 画面要件

- 対象画面：メイン画面
  - タスク内容を表形式で表示
  - 一度に大量のタスクを表示すると一覧性が低下するため、1ページあたり最大20件とする。
  - 20件を超過する場合は、ページング機能により複数ページに分割し、ユーザーが任意のページへ切り替えられるようにする。
  - 全ページ中で、現在何ページ目を表示しているのかがユーザーに分かるようにする。
  - また、全タスク件数に対して、現在何件目から何件目までを表示しているのかがユーザーに分かるようにする。例：1～20件 / 全87件
  - タスクが0件の場合は、「現在、未完了のタスクはありません。」とメッセージを表示する。
  - タスクの並び順は、タスクIDの昇順で表示する。各項目の並び替え機能は対象外とする。
