# Issue 5 ユーザー認証機能の追加 設計書

## 1. 概要

本件では、以下の機能について設計を実施する
・ユーザー認証機能
・Amazon RDS（MySQL）
・ユーザー情報管理

## 2. 基本設計（フロントエンド）

### 2.1 画面設計

既存のログイン画面を使用する。

認証成功時：

ログイン画面
    ↓
メイン画面

認証失敗時：

ログイン画面
    ↓
ログイン画面
＋
「ユーザーIDまたはパスワードが違います」

ログイン失敗時もログイン画面自体は変更せず、エラーメッセージを表示する。

### 2.1 画面遷移

```text
┌──────────────┐
│   ログイン画面   │
└──────┬───────┘
       │
       │ POST /login
       ↓
┌──────────────┐
│   ユーザー認証   │
└──────┬───────┘
       │
   ┌───┴────┐
   │        │
 成功      失敗
   │        │
   ↓        ↓
┌──────┐  ┌──────────────┐
│メイン画面│  │   ログイン画面  │
└──────┘  │＋エラーメッセージ│
          └──────────────┘
```

## 3. 基本設計（バックエンド）


### 3.1 システム構成

以下の構成とする。

```text
ユーザー
   ↓
EC2
   ↓
Spring Boot
   ↓
RDS（MySQL）
```

RDSはPublic Accessを無効とし、EC2からのみ接続できる構成とする。

---

### 3.2 ユーザー認証機能（処理の流れ）

以下の流れでユーザー認証を実施する。

1. ユーザーがログイン画面にユーザーID・パスワードを入力する。
2. ログインボタン押下により、`POST /login`を実行する。
3. `LoginController`がユーザーID・パスワードを受け取る。
4. `AuthenticationService`がユーザー認証処理を実行する。
5. `UserRepository`を使用して、ユーザーIDをもとにRDSの`users`テーブルを検索する。
6. ユーザーが存在する場合、入力されたパスワードとDBに保存されたパスワードハッシュを照合する。
7. パスワードが一致した場合、認証成功とする。
8. 認証成功時はSessionにログインユーザー情報を保存し、メイン画面へリダイレクトする。
9. ユーザーが存在しない、またはパスワードが一致しない場合は認証失敗とする。
10. 認証失敗時はログイン画面へリダイレクトし、エラーメッセージを表示する。

---

### 3.3 アプリケーション構成

以下の責務に分離する。

```text
LoginController
      ↓
AuthenticationService
      ↓
UserRepository
      ↓
RDS（MySQL）
```

#### LoginController

* ログインリクエストを受け取る。
* 認証処理をServiceへ依頼する。
* 認証結果に応じて画面遷移を行う。

#### AuthenticationService

* ユーザーIDをもとにユーザー情報を取得する。
* 入力されたパスワードとDBに保存されたパスワードハッシュを照合する。
* 認証結果をControllerへ返却する。

#### UserRepository

* `users`テーブルからユーザー情報を取得する。
* ユーザーIDを条件として検索する。

## 4. DB設計

### 4.1 データベース

| 項目   | 内容              |
| ---- | --------------- |
| DBMS | MySQL           |
| DB名  | `java_demo_app` |

### 4.2 usersテーブル

| No | カラム名          | 型            | NULL | 制約     | 説明                  |
| -- | ------------- | ------------ | ---- | ------ | ------------------- |
| 1  | id            | BIGINT       | NO   | PK     | ユーザー識別子             |
| 2  | user_id       | VARCHAR(50)  | NO   | UNIQUE | ログイン時に使用するユーザーID    |
| 3  | password_hash | VARCHAR(255) | NO   | -      | BCryptでハッシュ化したパスワード |

### 4.3 パスワード

パスワードはBCryptを使用してハッシュ化する。

DBには平文のパスワードを保存せず、ハッシュ値のみを保存する。
